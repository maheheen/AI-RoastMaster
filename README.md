# **App Name**: RoastMaster AI

## Core Features:

- Webcam Capture: Capture a user's image using the device's webcam.
- Image Submission to Gemini: Submit the captured image to the Gemini Vision API for roast generation.
- AI Roast Generation: Generate a savage, yet safe-for-event, roast of the user's image using Gemini with specific prompt instructions and moderation layers (word filter backup and a kill-switch tool)
- Text-to-Speech Playback: Convert the AI-generated roast text into speech and play it aloud.
- Roast Display: Display the AI-generated roast text on the screen in real time.
- Performance Tracking: Tracking performance metrics (roasts per hour, crowd retention, etc.) to iterate
- Backend Roast Prompting: Backend handles prompt management.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) for a dramatic and slightly intimidating feel.
- Background color: Dark gray (#333333) for a stark and modern contrast.
- Accent color: Electric green (#7CFC00) for highlighting the roast text and CTAs.
- Body and headline font: 'Space Grotesk' (sans-serif) for a computerized, techy feel; 'Inter' (sans-serif) for longer amounts of body text
- Code font: 'Source Code Pro' for displaying any backend configuration or prompt snippets.
- Use icons with a playful and slightly aggressive style.
- Use brief animations or emojis during roast display and speech playback.
